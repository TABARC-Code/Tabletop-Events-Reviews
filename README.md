# Tabletop Events Calendar — Reviews

Post-event ratings and testimonials for [Tabletop Events Calendar](https://github.com/TABARC-Code/tabletop-gaming-events-calendar) organisers.

**Not built yet.** This repo is reserved ahead of time, same as the rest of this family of plugins.

The idea: a review is gated to people who actually RSVP'd to that specific event (checked against the core plugin's own RSVP list), so a rating can't be faked by someone who was never there — the same trust-building instinct behind the core plugin's Verified Organiser badge, applied to feedback instead of a manual allow-list.

Requires [Tabletop Events Calendar](https://github.com/TABARC-Code/tabletop-gaming-events-calendar) once it exists.
